Topic: {TOPIC}

Build an essay outline: a defensible thesis, 3-5 argument sections each with the evidence
that would support it, the strongest counterargument and a response to it, and a list of
sources worth citing (real ones — verify they exist; never invent citations).
Write the outline to a markdown file here. Do not write the essay itself.
